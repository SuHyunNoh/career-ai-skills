# 고정 프로필

지원할 때마다 바뀌지 않는 기준값. **사례 은행에 근거가 있는 것만** 쓴다. role-match가 결격 조건과 자리 정체성을 판정할 때 이 파일을 쓴다.

## 형식
```
## 역할 성격 비중 (합 100)
- 사업을 만드는 일 (0→1):   __%  근거 사례:
- 개선·운영 (1→10, 턴어라운드): __%  근거 사례:
- 전략·기획 (분석, 보고, 체계):   __%  근거 사례:
- 직접 영업·계약:             __%  근거 사례:

## 레벨
- 연차 · 직급 · 조직 리딩 규모:

## 도메인 깊이
- 깊음(3년+):
- 얕음(1년 이하):

## 근거 있는 기능
- (예: 가격 정책 설계, 채널 입점, 고객 인터뷰 …)

## 근거 없는 기능 — 결격이 될 수 있는 지점
- (예: 예산 편성, 해외 법인 운영, 기술 아키텍처 …)
```

## 만드는 법
- 비중은 사례 수와 기간으로 지원자와 함께 정한다. 지원자가 원하는 비중이 아니라 **근거가 있는 비중**이다. 원하는 쪽은 direction.md에 쓴다.
- '근거 없는 기능'은 지원자가 지원하고 싶은 자리의 공고에서 자주 보이는 필수 요건 중 사례가 없는 것들이다. 숨기지 않는다. 지원 범위를 정하는 데 쓴다.
