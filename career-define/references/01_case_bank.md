# 사례 은행

## 사례 카드 형식
```
## [사례명 — 주도한 일, 예: "정체된 B2B 상품 재설계"]
- 기간 · 역할 · 팀 규모:
- 문제: 왜 이 일이 필요했나 (시작 시점의 숫자가 있으면)
- 내가 한 것: 직접 한 것 / 리드한 것 구분
- 결과: 숫자 + 기준(기간, 비교 대상) + 출처 유형(공식 / 대시보드 / 기억)
- 실패·한계: 안 된 것, 다시 하면 바꿀 것
- 능력 태그: 0→1, 턴어라운드, 데이터 분석, 파트너십, 조직 운영 …
- 실무 수준: 면접에서 세부 질문을 받아도 버틸 수 있나 (도구, 쿼리, 계약 조건 등)
```

## 질문 은행
**숫자**
- "그 %는 언제부터 언제까지, 무엇 대비인가요?"
- "그 숫자는 어디서 본 건가요? 공식 보고, 대시보드, 기억 중 어느 쪽인가요?"
- "시작할 때 숫자는 얼마였나요?"

**기여**
- "본인이 직접 한 것과 팀이 한 것을 나누면요?"
- "본인이 없었다면 무엇이 달랐을까요?"

**실무 수준**
- "그 도구는 직접 썼나요? 어느 수준까지요? (예: 쿼리라면 조인·집계·윈도우 함수까지)"
- "계약이라면 조건 협상을 직접 했나요? 규모와 기간은요?"

**실패**
- "이 일에서 가장 안 된 것은 무엇인가요?"
- "다시 한다면 무엇을 바꾸겠어요?"

**빠진 사례 찾기**
- "가장 오래 붙잡고 있던 문제는 무엇이었나요?"
- "아무도 하지 않으려던 일을 맡은 적이 있나요?"

## 규칙
- 한 번에 사례 하나, 질문 3개 이하.
- 답이 없는 칸은 비워 두고 '미확인'이라고 적는다.
