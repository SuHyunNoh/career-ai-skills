# 5. 전략·플라이휠

## 비전 정렬 (새로 짓기 전에)
- 회사·대표가 이미 쓰는 문장 3~6개를 원문 그대로 모아 층으로 정렬: 회사 비전 / 제품·서비스별 문장
- 빠진 연결 하나만 제안(예: 구매와 구매 사이의 '다시 올 이유')
- 판단 질문 1개로 압축: "이 일이 ○○를 하게 하나?"

## 플라이휠
- 고객 여정 기준(예: 구매 전·사용 중·사용 후)으로 원을 그리고, 순간마다 **핵심 수익 모델을 색으로** 표시
- 가운데는 순환할수록 쌓이는 자산(데이터·관계·신뢰 등)
- 끊긴 고리(예: 쌓인 자산 → B2B 영업)를 별도 색 화살표로
- SVG 규칙: viewBox, 라벨은 짧게, 화살표에 의미 라벨, role="img" + aria-label, 텍스트-선 겹침 확인

## 우선순위
| 순위 | 플라이휠 위치 | 사업 | 모델 | 먼저 확인할 것 |
- 순위가 의존 관계인지 명시(A가 열려야 B가 가능)
- 배분: 캐시카우 / 새 사업군 1개 / 탐색 비율, 외부 변수(투자·지원사업 결과)별 시나리오
- 선정 기준 5개 예: 접점 확보, 6개월 내 현금, 기존 자산 재사용, 약점(계절성 등) 완화, 현재 인원으로 가능
