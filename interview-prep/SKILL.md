# Interview Prep — 면접 준비는 내 경력의 번역이다

예상 질문 50개를 뽑아 외우게 하지 않는다. **이 면접 단계가 무엇을 보는지 정하고, role-match의 빈 곳(번역 필요·없음)에서 반드시 나올 질문부터 준비한다.** 면접이 끝나면 복기해 다음 면접에 반영한다.

## 입력
- 필수: 공고, 면접 단계(서류 후 1차 / 실무 / 임원 / 최종 등)와 아는 정보(면접관 역할, 형식, 시간)
- 권장: role-match 결과, 사례 은행(career-define). 없으면 role-match를 간단히 먼저 돌린다
- 복기 모드: 면접에서 실제로 받은 질문(기억나는 대로)과 지원자의 답 요약

## 절대 원칙
1. **단계마다 보는 것이 다르다.** 같은 질문 목록을 모든 단계에 쓰지 않는다.
2. **빈 곳부터.** '번역 필요'·'없음' 포인트는 질문이 반드시 나온다고 보고 답을 먼저 만든다.
3. **답은 지원자의 사례로만.** 사례 은행에 없는 경험을 지어내지 않는다.
4. **복기는 원문 그대로.** 질문을 면접관이 한 말에 가깝게 적고, 해석은 따로 적는다.

## 워크플로우
1. **이 단계가 보는 것** → `references/01_questions.md`의 단계 표에서 고른다.
2. **예상 질문** — 포인트별 1~2개 + 공통 질문 + 꼬리질문 (`01_questions.md`).
3. **답 초안** → `references/02_answers.md`. 30초 / 2분 두 길이.
4. **실무 검증 대비** — 공고가 도구·분석을 직접 요구하면 연습 문제를 만든다 (`02_answers.md`).
5. **역질문** — 4축에서 이 회사·이 단계에 맞는 것 3~4개.
6. **복기** (면접 후) → `references/03_debrief.md`.

## 출력 (한 장)
1. 이 단계가 보는 것 한 줄
2. 반드시 나올 질문 3개와 답 초안(30초)
3. 그 밖의 예상 질문과 답의 뼈대
4. 실무 연습(해당될 때)
5. 역질문 3~4개
6. 면접 직후 기록할 칸(복기 양식)

## 하지 않는 것
- 모범 답안 암기형 문장. 지원자가 자기 말로 다시 말할 수 있는 뼈대로 준다.
- 면접관 개인에 대한 조사. 공개된 직무 발언·인터뷰까지만.
